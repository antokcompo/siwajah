1. Ringkasan Eksekutif

Apa yang dibangun

Aplikasi web untuk menghitung kehadiran harian dan penggajian karyawan konstruksi, menggantikan proses manual yang sepenuhnya bergantung pada file ekspor mesin absen tanpa kontrol kualitas.

Mengapa dibutuhkan

Analisis terhadap data mesin absen bulan Juni 2026 mengungkap masalah serius:

23%
data tidak bisa dihitung otomatis
7 hari
mesin gagal berturut-turut
553
hari-orang tidak terekam
0
audit trail yang tersedia
Tanpa sistem, setiap bulan penggajian menghadapi risiko: membayar kurang (sengketa ketenagakerjaan) atau membayar lebih (kerugian operasional), keduanya tanpa bukti yang bisa diaudit.

Ruang lingkup MVP

Masuk MVP

  • Import data mesin absen
  • Perhitungan kehadiran otomatis
  • Deteksi anomali massal
  • Koreksi manual + audit trail
  • Approval lembur
  • Perhitungan rupiah gaji & lembur
  • Rekap bulanan + ekspor Excel
  • Tutup periode + kunci data

Tidak masuk MVP

  • Aplikasi mobile karyawan
  • Integrasi langsung ke mesin absen
  • Multi-lokasi / multi-proyek
  • Slip gaji cetak
  • Perhitungan PPh 21
  • BPJS / potongan otomatis
  • Cuti/izin/sakit (modul terpisah)
  • Dashboard analitik lanjutan

5.4 Jalur B — Koreksi Anomali Massal (Insiden Mesin)

Dipicu otomatis ketika jumlah karyawan LENGKAP turun di bawah 50% dari rata-rata 7 hari kerja sebelumnya.

Prinsip dasar: Karyawan tidak dirugikan atas kegagalan alat perusahaan. Ada bukti parsial (scan masuk ATAU pulang) = dianggap hadir penuh.

8. Arsitektur & Teknologi

Frontend
React + Vite
Hosting
Netlify
Database
Supabase (PostgreSQL)
Logika Bisnis
Supabase RPC

Prinsip arsitektur

  1. Data mentah immutable — scan dari mesin tidak pernah diubah setelah import
  2. Semua aturan bisnis di server — frontend hanya tampilan dan input
  3. RLS aktif di semua tabel — akses data sesuai role
  4. Konfigurasi di database — tidak ada hardcode parameter bisnis
  5. Audit trail otomatis — setiap perubahan tercatat via trigger

Stack lengkap

LapisanTeknologiAlasan

HostingNetlifyGratis untuk skala ini

Logika bisnisSupabase RPC (SECURITY DEFINER)Server-side enforcement
AuthSupabase Auth (email + password)Terintegrasi dengan RLS
Ekspor ExcelExcelJS via Netlify FunctionServer-side
NotifikasiFonnte / Wablas (WhatsApp)Peringatan anomali — opsional

Catatan desain

  • scan_mentah tidak pernah di-UPDATE atau DELETE
  • absensi_harian bisa di-UPDATE melalui koreksi
  • koreksi_log mencatat setiap perubahan — immutable
  • gaji_bulanan hanya ditulis saat tutup periode
  • RLS: tabel karyawan dan gaji_bulanan dibatasi ke Admin dan HRD
  • Soft delete: karyawan dinonaktifkan, bukan dihapus
  • Composite key (karyawan_id, tanggal) mencegah duplikasi
